# minios-mcp
> MiniOS MCP bridge exposing a running MiniOS instance as JSON-RPC tools over stdio, booting os.img in QEMU and owning a pty-backed serial console for edit/compile/link/run workflows.

- Python 3, standard library only (no external deps)
- One QEMU child per server instance; terminated on every exit path
- Tools include minios_boot, minios_send, minios_write, minios_python, minios_install, minios_test, minios_poweroff
- Strict path validation (relative, no .., limited charset) and content validation (printable ASCII only)
- LogBuffer with bounded capacity, absolute byte positions, and marker waits
- Addon system supports git-backed installs with chunked editor writes, build/verify steps, and registry tracking
- Timeouts clamped to [500,600000] ms; boot/prompt/poweroff markers are configurable via env
- Pytest suite (47 test files) with unit, protocol, validation, and QEMU-backed BDD layers

## Architecture
MiniOSSession owns QEMU + pty + LogBuffer + cursor. MCPServer implements JSON-RPC 2.0 dispatch over stdio, routing to session methods or minios_addons. AddonState persists installed metadata; validate_path/validate_content enforce ramdisk and editor constraints before any write.

## API
Exposed MCP tools (see TOOLS list in minios_mcp.py):
- minios_boot, minios_status, minios_snapshot
- minios_send, minios_expect, minios_write, minios_cat
- minios_python, minios_py_eval
- minios_addons, minios_install, minios_test
- minios_poweroff

All tool results are JSON; errors returned as isError with text.

## Configuration
Environment variables (with defaults):
- QEMU, MINIOS_IMAGE, MINIOS_MEM=1G
- MINIOS_TMO_BOOT, MINIOS_TMO_PROMPT, MINIOS_TMO_EXPECT, MINIOS_TMO_POWEROFF
- MINIOS_ADDONS_DIR, MINIOS_GIT, MINIOS_ADDON_STATE, MINIOS_PIDFILE
- MINIOS_LOG_CAP=1048576

## Getting Started
```bash
python3 -m mcp.minios_mcp
```
Requires os.img and QEMU. BDD tests skip unless QEMU + image present.

## Dependencies
- QEMU (qemu-system-x86_64)
- git (for addon installs)
- MicroPython inside MiniOS for src/*.py helpers (build.py, shell.py, test.py)

## Testing
pytest with protocol unit tests, validation, LogBuffer, and optional QEMU BDD scenarios. Set MINIOS_SKIP_BDD=1 to force skip. FakeOS used for addon install tests.
